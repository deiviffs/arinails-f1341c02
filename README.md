# Glamify Hub

Prompt para Lovable:

Crea una landing page móvil (estilo Linktree/BioLink) con una estética femenina, glamurosa, elegante y sofisticada (estilo "aesthetic" para salón de belleza/estética de uñas, cejas, pestañas y cabello). Usa una paleta de colores con tonos rosa pastel, beige/nude, blanco y toques de dorado sutil, con tipografía elegante y bordes suaves o redondeados.

1. Cabecera (Header):

Imagen de perfil o logo circular en la parte superior central.

Nombre de la marca / negocio justo debajo.

Una breve descripción/biografía (ej. "Uñas • Cejas • Pestañas • Cabello").

En la esquina superior derecha, incluye un icono discreto de usuario (login/administrador).

2. Lista de Botones de Enlaces (Sección Principal):

Diseña 4 botones verticales principales bien estilizados, con animaciones sutiles al pasar el cursor o presionar:

Instagram (con el icono de Instagram).

Facebook (con el icono de Facebook).

WhatsApp (con el icono de WhatsApp).

TikTok (con el icono de TikTok).

Configura los enlaces de estos botones con variables o href="#" vacíos como marcadores de posición (INSTAGRAM_URL_HERE, FACEBOOK_URL_HERE, WHATSAPP_URL_HERE, TIKTOK_URL_HERE) para editarlos fácilmente en el código.

3. Sistema de Administración Simulado (Admin Single-User):

Al tocar el icono de usuario en la esquina superior derecha, abre un modal de Inicio de Sesión simple para un único usuario administrador.

Una vez autenticado como administradora, habilita una vista o panel especial sobre la misma página donde el administrador pueda:

Ocultar o mostrar cualquiera de los botones existentes mediante switches (toggle).

Agregar un nuevo botón personalizado ingresando solo tres campos: Texto del botón, Icono/Logo y Enlace/URL.

Editar o eliminar enlaces existentes.

Asegúrate de que la interfaz sea totalmente responsiva (optimizada principalmente para teléfonos móviles) y limpia.
